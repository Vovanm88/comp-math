# Лабораторная работа 1  
Ввод / Вывод данных в разных форматах

**Поддерживаемые форматы ввода:**  
`input.txt` • `input.json` • `input.csv`

**Поддерживаемые форматы вывода:**  
`output.txt` • `output.json` • `output.csv`

---

## Задание 1. Скалярное произведение двух векторов

В файле одна строка — числа первого вектора, вторая строка — числа второго вектора.

**Пример input.txt**
```
1.5 2  -3  4.2
-1   0   5  -2
```

**Ожидаемый output.txt**
```
-3.3
```

---

## Задание 2. Поэлементное сложение векторов / матриц / тензоров

Первая строка — размерность (n₀ n₁ … nₖ), затем два тензора одинаковой формы, заданные построчно.

**Пример input.txt**
```
2 3
1 2 3
4 5 6
7 8 9
1 0 2
3 1 4
0 5 -1
```

**Ожидаемый output.txt**
```
2 3
8 8 11
7 6 10
```

---

## Задание 3. Умножение матриц

Первая строка — размеры первой матрицы `n m`  
Далее n строк по m чисел — первая матрица  
Затем m строк по k чисел — вторая матрица (размер m×k)

**Пример input.txt**
```
2 3
1 0 2
-1 3 1
3 1
2
0
4
```

**Ожидаемый output.txt**
```
2 2
9 8
7 4
```

---

## Задание 4. QR-разложение

Вводится прямоугольная матрица.  
Выводятся матрицы Q, R и ранг.

**Пример input.txt**
```
3 3
4  12 -16
12 37 -43
-16 -43 98
```

**Пример output.txt**
```
Q:
0.22  0.80  0.57
0.66  0.40 -0.63
-0.71  0.44 -0.55

R:
18.00  48.00  -64.00
 0.00  5.00   -10.00
 0.00  0.00    9.00

Ранг: 3
```

---

## Задание 5. LUP-разложение

Выводятся матрицы L, U, вектор перестановок P (или матрица P) и ранг.

**Пример input.txt**
```
3 3
2  1  1
4 -6  0
-2  7  2
```

**Пример output (упрощённый txt)**
```
L:
1    0    0
2    1    0
-1  -1.5  1

U:
2  1   1
0 -8  -2
0  0   3

P: [0, 1, 2]  (или перестановка строк)
Ранг: 3
```

---

## Задание 6. Сингулярное разложение (SVD)

Выводятся матрицы U, вектор сингулярных значений Σ, матрица Vᵀ (или V)

**Пример input.txt**
```
2 2
4  11
14 5
```

**Пример output.txt**
```
U:
-0.404 -0.915
-0.915  0.404

Σ:  [19.403  0.000]
    [ 0.000  4.597]

Vᵀ:
-0.800  -0.600
 0.600  -0.800
```

## Задание 7. Решение СЛУ методом Гаусса (прямой ход + обратный)

**Пример input.txt**
```
3
2  1  -1   8
-3 -1  2  -11
-2  1  2   -3
```

**Ожидаемый output.txt**
```
x₁ = 2
x₂ = 3
x₃ = -1
```

**Пример input** — такой же, как в задании 7

**Вывод** — тот же + использованное разложение и погрешность (если выводится)

## Задание 9. Решение СЛУ итерационным методом
